# CFGéo B4 – Formats, interfaces

Support du cours **B4c « Formats, interfaces »** du module B4 « Géomatique & TI » du
Centre de formation géomatique suisse (Romandie).

Enseignant : Régis Longchamp

## Le cours

Pour être utilisée, une donnée géographique doit être codée dans un **format** qu'un logiciel
sait interpréter, puis échangée entre systèmes à travers des **interfaces**. Ce cours donne les
clés pour comprendre comment l'information est codée, choisir un format adapté, et faire
dialoguer des systèmes différents.
